# Prelegal

A platform for drafting common legal agreements

## Status

> **In progress** — Prelegal is currently under development and is expected to be completed within one week (by **October 30, 2026**).

## Mutual NDA prototype

The Next.js application is in [`frontend/`](frontend/README.md). To run it locally:

```bash
cd frontend
npm install
npm run dev
```

The prototype builds a mutual NDA preview and downloads it as a PDF. It is a general starting point, not legal advice.
