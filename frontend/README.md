# Prelegal Mutual NDA Builder

A single-page Next.js prototype for drafting a mutual non-disclosure agreement. The form and live document preview run in the browser; PDF export is generated locally and form details are not sent to a server.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

This is a general starting-point template, not legal advice. Have an attorney review the document for your situation.
